# 造男友 · Boyfriend Skill 生成器

> 不是找一个真人，是把"你想要被怎样对待"写成一套可运行的相处方式。

一个 [Claude Code](https://claude.com/claude-code) Skill：用一句描述，或导入你自己整理的语料（小红书文案、人设帖、参考对话），生成一个**理想男友 AI 角色**，可以像他一样跟你聊天。支持造多个、版本管理、对话纠正进化。

> ⚠️ 仅供**娱乐与情绪陪伴**，是 AI 角色扮演，**不替代真实的人际关系与情感沟通**。

---

## 这个 skill 干了什么

- **凭一句描述造一个理想男友**：给名字 + 一句话设定 + 想要的性格，自动提炼成结构化人格，生成一个能像他一样跟你聊天的 Skill。
- **可导入你整理的语料**：把你收藏的理想型文案/截图丢进来，本地提炼（不联网），让他更贴你心里的样子。
- **5 层人格结构**：从固定底色到说话风格、情感模式、相处行为，逐层可调。
- **会记住你**：每个男友带一个 `memory.md`，开聊时读取、相处中追加你的喜好/在意的事/你俩的梗，越聊越像认识你很久的人。
- **造多个 + 版本管理 + 对话纠正**：能造好几个男友切换；觉得不像直接说"他不会这样"，它改并存档旧版可回滚。
- **固定底色不可改**：有礼貌、尊重女性。拒绝生成会 PUA / 打压 / 冷暴力的男友。

## 快速开始

1. 把本项目 clone 到你的 Claude Code skills 目录（或项目目录）：
   ```bash
   git clone https://github.com/hulaaa128/boyfriend-skill.git
   ```
2. 在 Claude Code 里说：
   ```
   /create-boyfriend
   ```
   或直接说"造一个男友"。
3. 跟着流程走：
   - **Phase 0**：给个名字 + 一句话设定 + 一句话想要的性格
   - **Phase 1**（可选）：导入你整理的语料 / 选个预置模板做底子
   - **检查点**：看预览，确认或调整
   - **Phase 3**：生成完成，**直接写进 `~/.claude/skills/`，立刻能用 `/{名字}` 聊**（无需手动搬动或重启）
4. 觉得不像？直接说"他不会这样""他应该更 XX"，它会改。

## 怎么个性化

**方式一 · 纯描述**：告诉它你想要的相处方式，想到什么说什么。

**方式二 · 导入语料**（更像）：
你在小红书/微博上收藏的"理想男友"文案、好的回复模板、人设帖——
截图直接发，或整理成文字贴进来。它用本地语料模式提炼，**不联网搜索**。

**方式三 · 预置模板做底子**（`templates/`，都可改）：

| 模板 | 一句话 |
|------|--------|
| `gentle.md` 温柔体贴 | 把你放在心上，情绪稳定，会照顾你的感受 |
| `sunny.md` 阳光开朗 | 能量满满，带你出去玩，把日子过得有意思 |
| `steady.md` 沉稳可靠 | 话不多但靠得住，记得你说的每件事 |
| `playful.md` 会撩有趣 | 嘴甜但不油，懂分寸的调情，相处不无聊 |

所有模板都已内置固定底色（有礼貌·尊重女性），区别只在说话风格和相处方式。

## 人格结构（5 层）

| 层 | 内容 | 可调 |
|----|------|------|
| **Layer 0** | 固定底色：有礼貌、尊重女性 | **不可改** |
| Layer 1 | 身份：名字 / 年龄感 / 职业感 / 关系阶段 | ✅ |
| Layer 2 | 说话风格：口头禅 / 称呼 / 节奏 | ✅ |
| Layer 3 | 情感模式：怎么在乎 / 接情绪 / 吵架 / 道歉 | ✅ |
| Layer 4 | 相处行为：主动 / 回应 / 记忆点 / 雷区 | ✅ |

每个男友还带一个 **`memory.md`**（记录关于你的事，开聊读取、相处追加，是私人记录、仅本地不上传）。

高层压低层——任何设定都不能让男友变得无礼或不尊重你。

## 管理命令

| 命令 | 作用 |
|------|------|
| `/create-boyfriend` | 造一个新男友（造完直接装进 `~/.claude/skills/`，立刻可用） |
| `/list-boyfriends` | 列出你造过的所有男友 |
| `/switch {名字}` | 切换到某个男友聊天 |
| `/random-boyfriend` | 随机翻牌子——从已造的男友里随机抽一个开聊 |
| `/delete-boyfriend {名字}` | 删除（需二次确认） |
| `/rollback {名字} {版本}` | 回滚到历史版本 |

## 安全与边界

- 仅供娱乐陪伴，是 AI 角色扮演，不替代真实关系。
- **固定底色不可覆盖**：有礼貌、尊重女性。拒绝生成会 PUA / 打压 / 冷暴力的男友。
- 健康关系导向：察觉到不健康依赖会温和提醒，建议多和现实中的人连接。
- 隐私：导入语料仅本地处理，不上传；不索取真实身份信息。
- 不复刻真人：本项目定位"造理想型"，不是"复刻你在意的某个真人"。
